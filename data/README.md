# Data

This project uses the public **PaySim** dataset. The CSV is not included in this repository because of its size (about 470 MB) and because it is freely available from Kaggle.

## Source

**Synthetic Financial Datasets for Fraud Detection (PaySim)**, Kaggle
https://www.kaggle.com/datasets/ealaxi/paysim1

File: `PS_20174392719_1491204439457_log.csv`

## Setup

1. Download the CSV from the Kaggle page above (a free Kaggle account is required).
2. Place it in this folder under `raw/`:

```
data/
└── raw/
    └── PS_20174392719_1491204439457_log.csv
```

3. Run the pipeline from the repository root:

```bash
python src/fraud_capstone_pipeline.py
```

To keep the CSV somewhere else, set the `PAYSIM_PATH` environment variable to its full path instead.

## About the data

PaySim is a synthetic dataset generated by a simulator based on one month of real mobile money transactions. It contains no Agribank customer or transaction data, and amounts are simulated currency units, not pesos.

| Item | Value |
|---|---|
| Transactions | 6,362,620 |
| Columns | 11 |
| Time span | 743 hourly steps (about 30 days) |
| Fraud cases | 8,213 (0.129%) |

The `data/raw/` folder is listed in `.gitignore`, so the CSV will not be committed by mistake.

## Reference

Lopez-Rojas, E. A., Elmir, A., and Axelsson, S. (2016). PaySim: A financial mobile money simulator for fraud detection. *Proceedings of the 28th European Modeling and Simulation Symposium (EMSS).*
